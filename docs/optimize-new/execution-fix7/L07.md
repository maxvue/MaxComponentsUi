## 1. Objetivo
Garantir integridade arquitetural na distribuição do pacote, isolamento de bundle e proteção completa a consumidores:
- **`R24/E11-04`:** Mapa explícito de exports no `package.json` sem wildcards (`*`), cobrindo rigorosamente todos os 117 componentes Vue, subpaths públicos e utilitários; CSS global estritamente opt-in (`dist/style.css`); obrigatoriedade de build fresco em `dist/`; budget transitivo de `MaxButton` rigorosamente respeitado abaixo do teto contratual de 238.886 bytes (resultado medido: 3.167 bytes bruto / 1.341 bytes gzip).
- **`R25/E11-05`:** Script de verificação de consumidores (`scripts/verify-consumers.mjs`) com diretório temporário exclusivo indexado por PID (`/tmp/max-consumer-<pid>-<hash>`) e tarball isolado; garantia de execução com limpeza rigorosa via bloco `finally` e handlers de sinal (`SIGTERM`, `SIGINT`, `SIGHUP`); concorrência sem race condition validada com duas instâncias simultâneas; cobertura completa de cenários reais: Node ESM sem opcionais, Node ESM com opcionais, TypeScript (`tsc --noEmit`), Vite production build, SSR/Nuxt streaming render, CSS global e temas SCSS compilados via `sass`, e rejeição determinística de subpaths inválidos (`ERR_PACKAGE_PATH_NOT_EXPORTED`).

- **Atualização de Catálogo:** O teste arquitetural `package-exports.test.ts` foi sincronizado para o total de 117 componentes Vue (incorporando `MaxInputHtml` e `MaxInputHtmlToolbar`), garantindo que 100% dos componentes possuem mapeamento estático individual com declaração de tipos `.d.ts` e export ESM.
