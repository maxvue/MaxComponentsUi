## Project Overview

`@maxvue/max-components-ui` is a Vue 3 component library built on top of PrimeVue 4, distributed as an ES module via npm. It wraps and extends PrimeVue with a custom theme (`MaxStyle`), locale (pt-BR), UnoCSS preset, and a set of form/layout/display components.

It depends on a sibling local package `@maxvue/max-use` (referenced as `file:../MaxUse`), which must be cloned alongside this repo at the same parent directory level.

## Commands

```bash
npm install               # Install dependencies (requires ../MaxUse to exist)
npm run dev:playground    # Run the playground for manual component testing
npm run type-check        # Run vue-tsc type checking
npm run lint              # Run ESLint + Stylelint with auto-fix
npm run build             # vue-tsc + vite build + copy themes to dist/
npm run test              # Run all tests (vitest run)
npm run test:watch        # Run tests in watch mode
npm run test:coverage     # Run tests with v8 coverage report
```

**Run a single test file:**
```bash
npx vitest run tests/components/MaxButton.test.ts
```

**After adding a new component, regenerate the resolver manifest:**
```bash
npx tsx src/scripts/generateResolver.ts
```

## Architecture

### Build Outputs (multi-entry)

The library builds four separate ES entries:

| Entry | Export path | Source |
|-------|-------------|--------|
| `index.es.js` | `.` (default) | `src/index.ts` — all Max components + `install()` plugin |
| `preset.es.js` | `./preset` | `src/presetMaxUno.ts` — UnoCSS preset for consuming apps |
| `resolver.es.js` | `./resolver` | `src/helpers/MaxComponentsUiResolver.ts` — unplugin resolver |
| `prime.es.js` | `./prime` | `src/prime/index.ts` — raw PrimeVue re-exports |

CSS is injected into `index.es.js` only (via `vite-plugin-css-injected-by-js`). Themes (`src/themes/`) are copied verbatim to `dist/themes/` post-build and are not bundled.

### `InputBase` — the core wrapper

All form input components must be wrapped by `InputBase` (`src/components/InputBase.vue`). It provides:
- PrimeVue `FloatLabel` + `IconField`/`InputIcon` layout
- Visual states: `done`, `error`, `caution`, `required`, `noStatus`
- Inline label mode, message/feedback line below the field
- Left/right icon slots (`icon`, `iconLeft`, `iconRight`, `iconPos`)

Any new input component should use `<InputBase>` as its outermost element.

### Styling

- **UnoCSS** (`virtual:uno.css`) — custom preset exported from `src/presetMaxUno.ts`. Utility classes like `pt-4`, `gap-2`, `color-blue-500`, `bg-background-300`, `hover-primary-600` are all custom rules defined there.
- **SCSS** — component-scoped `<style lang="scss">` blocks. Use CSS variables from the Max theme: `var(--background-300)`, `var(--blue-600)`, `var(--max-primary-500)`.
- **PrimeVue theme** — defined in `src/styles/style.ts` as `MaxStyle` (a `definePreset` from `@primeuix/themes`). Applied globally via `install()`.

### Stores (Pinia)

Three exported stores in `src/stores/`:
- `useIconStore` — caches Iconify SVG icon fetches
- `usePopoverStore` — controls `MaxPopover` open/close state
- `useToastStore` — controls `MaxToast` queue

### Component Auto-Import

`src/components-manifest.json` is generated by `src/scripts/generateResolver.ts`. It lists all component names and their aliases (snake_case, kebab-case, no-Max prefix). The resolver (`MaxComponentsUiResolver`) reads this file to resolve imports in consuming apps.

When a new `.vue` file is added to `src/components/`, run `generateResolver.ts` to update the manifest and aliases.

### Test Setup

Tests live in `tests/` and use Vitest + `@vue/test-utils` + `happy-dom`. Global setup in `tests/setup.ts` mocks:
- `localStorage`
- `getComputedStyle` (with pre-defined CSS var values)
- `fetch`
- `indexedDB`
- `virtual:uno.css` module
- Provides PrimeVue + Pinia globally to all mounted components
- Stubs `v-tooltip` and `v-maska` directives

### Code Conventions

- `<script setup lang="ts">` with typed `defineProps<Interface>()` and `defineEmits<{...}>()`
- 4-space indentation (enforced by ESLint `@stylistic/indent`)
- Single quotes, no trailing commas, semicolons required
- Template → Script → Style block order in `.vue` files
- Multiple export aliases for the same component are defined in `src/index.ts` (e.g. `MaxInputText`, `InputText`, `InputField` all point to the same file)
- `src/prime/index.ts` re-exports raw PrimeVue components that have no Max wrapper, so consuming apps can import everything from one source
