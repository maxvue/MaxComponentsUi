# Task 12 — MaxInputIconPicker: Endpoints Curados + SVG Sob Demanda

## O que mudou

### Removido
- Constante `POPULAR_ICONS` (~160 ícones mdi hardcoded) eliminada por completo.
- `fetch` para `https://api.iconify.design/search` removido.
- Uso de `<MaxIcon>` para renderizar os ícones dentro da lista da picker (evita acionar o store legado `useIcon.Store.ts`).

### Adicionado / Alterado

#### Props novas
- `listUrl` (default `/api/icons/picker`) — URL para listar/buscar ícones curados.
- `svgUrl` (default `/api/icons/picker/svg`) — URL para POST de resolução de SVGs.

#### Interface `IconEntry`
```ts
interface IconEntry { id: number; name: string; search: string; }
```
A lista curada retorna objetos, não strings simples.

#### `curatedIcons` substitui `apiIcons`
Ref `curatedIcons: IconEntry[]` armazena a lista curada atual (padrão ou filtrada).

#### `fetchCuratedIcons(query?)`
- Sem query → `GET /api/icons/picker` (lista curada completa).
- Com query → `GET /api/icons/picker?q=<termo>` (busca PT-BR FULLTEXT).
- Após carregar, chama `preloadInitialSvgs()` para pré-buscar SVGs das primeiras linhas visíveis.

#### `openDrawer`
- Ao abrir, limpa `svgCache`, `svgFetchQueue` e timers pendentes.
- Chama `fetchCuratedIcons()` imediatamente (sem query).

#### Busca com debounce
- `watchDebounced` mantido (400ms).
- Se `val.length < 2`: recarrega lista padrão via `fetchCuratedIcons()`.
- Se `val.length >= 2`: chama `fetchCuratedIcons(val)`.

#### SVG sob demanda
- `svgCache: ref<Record<string, string>>({})` — cache local de SVGs na instância do componente.
- `enqueueSvgFetch(names)` — enfileira nomes ausentes do cache, debounce 150ms, dispara `POST /api/icons/picker/svg` com lotes de até 200. Se sobrar fila após o splice, reagenda.
- `onScrollerScroll(event)` — listener no evento `@scroll` do VirtualScroller; estima linhas visíveis por `scrollTop / itemSize` + buffer de 2 linhas; coleta `icon.name` dessas linhas e chama `enqueueSvgFetch`.
- `preloadInitialSvgs()` — calcula ~17 linhas iniciais (600px / 40px + 2) e pré-busca seus SVGs logo após o carregamento da lista.

#### Renderização na célula
```html
<div v-if="svgCache[icon.name]" class="picker-icon-svg" v-html="svgCache[icon.name]" />
<div v-else class="picker-icon-placeholder" />
```
Sem `<MaxIcon>` — não aciona `useIcon.Store.ts` nem a tabela de 328k ícones.

O trigger (fora do drawer) continua usando `<MaxIcon>` normalmente.

#### SCSS
- `.picker-icon-svg` — wrapper 1.5rem × 1.5rem, `color: rgb(0 0 0 / 50%)` (modern notation), SVG ocupa 100%.
- `.picker-icon-placeholder` — retângulo cinza 1.5rem × 1.5rem enquanto o SVG não chegou.
- `.selected .picker-icon-svg` substitui `.selected .max-icon-div` na regra de cor primária.

## Decisões de implementação

| Decisão | Motivo |
|---|---|
| Debounce 150ms no fetch SVG | Evita rajadas ao scrollar rápido; um único POST cobre várias linhas |
| Lote máximo 200 por POST | Limite definido pela spec do endpoint |
| Limpar cache ao reabrir drawer | Garante dados frescos; o cache é leve (apenas SVGs visíveis) |
| Recarregar lista padrão quando search < 2 | UX: ao apagar a busca o usuário volta à lista curada |
| `nextTick` antes de `preloadInitialSvgs` | Garante que `rows.value` já reflete a nova lista antes de calcular o batch inicial |

## Concerns

- **Scroll event vs. VirtualScroller API**: O VirtualScroller do PrimeVue 4 não expõe um evento explícito com índices visíveis; usamos `@scroll` no elemento container e calculamos via `scrollTop / itemSize`. Isso é robusto mas depende de `itemSize=40` estar sincronizado com o CSS. Se o itemSize mudar, ajustar ambos.
- **svgCache por instância**: O cache não é compartilhado entre instâncias do componente (diferente do store legado). Para uso com múltiplos pickers na mesma página, cada um fará seus próprios fetches. Solução futura: extrair para um composable compartilhado.
- **Domínio relativo**: Os defaults `/api/icons/picker` e `/api/icons/picker/svg` funcionam quando a lib é usada em app no mesmo domínio. Para uso cross-domain, o consumidor deve passar as props `listUrl`/`svgUrl` com a URL completa.
